# TextField

A labelled text area for pasting what the user received, with a live counter.

- `.fr-field` label 14/600 `ink`; textarea `body` 16/400, padding `space-14`, 1px `line-strong`, radius `radius-12`, `surface` fill.
- Counter/hint below in `caption` 13/400: "67 / 10,000 characters" (mobile: "67 / 10,000").
- Label copy asks for fidelity: "Paste the message exactly as received", "Exactly as you received it". Conversation composer uses a 2-row variant with a 1px `line` border, radius `radius-10`, placeholder "Paste one message".
