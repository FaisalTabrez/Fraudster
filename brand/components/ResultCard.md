# ResultCard

The plain container for result sections: "Why we're warning you", "What we checked", "Limits of this result".

- `.fr-card`: `surface`, 1px `line`, radius `radius-16`, padding 28px desktop / 20px mobile. Heading `heading` (`heading-mobile` on mobile).
- Borders, not shadows. Never add a coloured left border.
- Result order is fixed: 1 ActionCard, 2 coverage Banner, 3 2–3 EvidenceItems, 4 CoverageList, 5 Limits, 6 TechnicalDetails (collapsed).
