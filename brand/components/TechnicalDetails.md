# TechnicalDetails

Module-level detail, collapsed by default, always last in the result.

- A `<details>` card; summary row min-height 60px, "Technical details" 16/600 with a `caption` meta: module count, unavailable count, gateway version, latency.
- Table body in `mono`; unavailable module rows show status `unavailable` in `coverage-fg` and their safe `detail` string.
- Always state that scores are not probabilities and no aggregate risk score is calculated. On mobile the table scrolls horizontally.
