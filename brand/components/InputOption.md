# InputOption

Large tap tiles for mobile step 1, "What did you receive?".

- `.fr-option`: min-height 88px, padding 16/18, radius `radius-16`, `surface`, 1px `line`.
- Selected (`aria-pressed="true"`): 2px `brand` border; icon well turns `brand-tint` with a `brand` icon. Unselected well: `sunken` / `ink-2`.
- Title 17/600; description 14px `caption`. Icons: `input-message`, `input-link`, `input-conversation`.
- Exactly three options in this order: A message, A link, A conversation.
