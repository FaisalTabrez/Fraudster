# PrivacyNote

A quiet reassurance placed just above the submit button.

- Lock icon (`privacy-lock`) + 14px `ink-2` text on `ground` inside a card; on mobile, where the page is already `ground`, add `.fr-privacy--on-ground` (`sunken`). Radius `radius-12`.
- Copy states the limits plainly: only what is pasted is checked, links are never opened, and the app keeps no history of what you submit. When a text check can send the message to an external analysis provider, say so and say that the provider handles and retains it under its own terms. Do not write "nothing is stored".
