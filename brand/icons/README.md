# Icons

24×24 stroke icons from the Fraudster UI template. Stored files are single-ink in `ink` (#1C211F); inline them with `stroke="currentColor"` to tint.

- `verdict-scam.svg` — octagon with exclamation. Potential scam, in `scam-fg`.
- `verdict-promotional.svg` — tag. Likely promotional, in `promo-fg`.
- `verdict-no-warning.svg` — empty shield, no tick. No strong warning found, in `clear-fg`.
- `verdict-unable.svg` — dashed circle with question mark. Unable to assess, in `unknown-fg`.
- `demo-data.svg` — flask. Demo-data banner, in `demo-fg`.
- `coverage-partial.svg` — triangle alert. Partial-check banner and "Unavailable" status, in `coverage-fg`.
- `coverage-unavailable.svg` — circle with slash. Checks-unavailable banner, in `coverage-strong-fg`.
- `check-ran.svg` — circle check, stroke 2.2. "Checked" status, in `clear-fg`.
- `check-not-applicable.svg` — dash, stroke 2.2. "Not applicable", in `caption`.
- `check-not-run.svg` — dashed circle, stroke 2.2. "Not run", in `caption`.
- `not-opened.svg` — eye with slash. "Not opened" URL badge, in `ink-2`.
- `back.svg` — chevron left. Mobile back button, in `ink`.
- `input-message.svg`, `input-link.svg`, `input-conversation.svg` — input-type options; `brand` when selected, `ink-2` otherwise.
- `privacy-lock.svg` — padlock. Privacy note, in `ink-2`.
- `remove.svg` — ×. Remove-link icon button, in `ink-2`.
