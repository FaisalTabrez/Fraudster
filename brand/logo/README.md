# Logos

- `fraudster-mark.svg` — the mark: a speech bubble with a pause sign in a `brand` (#1F4D43) rounded square; bubble in `ground` (#F4F2EC). App icon, favicon, avatar. Use on `ground`, `surface` or `ink`.
- `fraudster-mark-reversed.svg` — `ground` square, `brand` bubble. Use on `brand` backgrounds.
- `fraudster-lockup.svg` — mark + "Fraudster" wordmark (Public Sans 700, outlined) in `ink` (#1C211F). Headers, documents, slides on light grounds.
- `fraudster-lockup-reversed.svg` — reversed mark + wordmark in `ground`. Use on `brand` or `ink`.
- `fraudster-mark.png` (512×512), `fraudster-lockup.png` (916×224) — bitmaps for places that don't take SVG.
